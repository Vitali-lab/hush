# Hush

**Говори тихо. Печатать будем мы.**

Диктовка на устройстве для macOS. Зажми клавишу, скажи что нужно, отпусти — текст
появится у курсора в любом приложении. Без аккаунта, облака и телеметрии.

[**Скачать Hush для macOS**](https://github.com/Vitali-lab/hush/releases/latest/download/Hush-macOS-arm64.dmg) · [English version →](README.md)

```
macOS 14+ · Apple Silicon · ~8 МБ плюс модель 632 МБ при первом запуске
```


## Что умеет

- **Диктовка где угодно** — Slack, почта, Cursor, терминал, браузер. Текст
  вставляется в поле с курсором, поэтому работает любое поле ввода.
- **Полностью офлайн** — Whisper `large-v3` Turbo в CoreML на Apple Neural
  Engine. Аудио живёт в памяти и никуда не отправляется.
- **Легко для ресурсов** — ~130–200 МБ памяти при распознавании; модель грузится
  меньше двух секунд и выгружается после восьми минут тишины.
- **Два языка, один переключатель** — русский или английский для интерфейса и
  распознавания одновременно. RU слушает только русский, EN — только английский.
- **Любой хоткей** — удерживай Fn, правый Option, комбинацию или запиши свою
  клавишу. Режим удержания или старт/стоп по нажатию.
- **Пять тем** — Системная, Светлая, Песочная, Графит, Полночь. Две светлые, две
  тёмные и одна следует за macOS.
- **Мелочи для удобства** — свои слова, сниппеты, удаление слов-паразитов, четыре
  звука старта, история с поиском, автозапуск.
- **Тихо по дизайну** — только меню-бар, без иконки в Dock и фоновых демонов.

## Установка

1. Скачай DMG и открой его.
2. Перетащи **Hush** в **Applications**.
3. Запусти Hush и разреши:
   - **Микрофон** — чтобы слышать тебя.
   - **Универсальный доступ (Accessibility)** — для глобального хоткея и вставки
     текста в другие приложения. macOS может попросить перезапустить Hush.
   - **Речевую модель** — одна загрузка (~630 МБ), дальше всё офлайн.
4. Зажми хоткей, говори, отпусти.

Если хоткей всё равно не срабатывает, включи ещё **Input Monitoring** для Hush и
перезапусти приложение.

## Как пользоваться

| Действие | По умолчанию |
| --- | --- |
| Старт / стоп диктовки | Зажми `Fn`, говори, отпусти |
| Отмена во время записи | `Esc` |
| Открыть настройки | `⌘ ,` |
| Выход | `⌘ Q` |

Хоткей настраивается в **Настройки → Основное → Горячая клавиша**:

1. Нажми **Записать**.
2. Нажми любую комбинацию, либо одну клавишу Fn / F1–F20 / модификатор.
3. Выбери **Удерживать** или **Нажатие — старт/стоп**.

Работает любая клавиша. Обычная буква будет срабатывать и во время набора,
поэтому модификатор (⌘, ⌥, ⌃, ⇧) или F-клавиша надёжнее. Пресеты: `Fn`,
`Правый ⌥`, `Fn ×2`, `⌃⌥Пробел`.

После отпускания текст вставляется у курсора. Если нет доступа Accessibility,
Hush копирует текст в буфер.

## Языки, звуки, темы

Переключатель языка в **Настройки → Основное** (или `EN / RU` в поповере
меню-бара) меняет и интерфейс, и язык распознавания.

Звуки старта находятся в **Настройки → Основное → Поведение**: Колокольчик,
Блум, Щипок или Тик. Каждый проигрывается при выборе; на остановке звучит тихий
щелчок, а весь звук можно выключить.

Темы находятся в **Настройки → Основное → Тема**:

| Тема | Режим | Характер |
| --- | --- | --- |
| Системная | следует за macOS | фиолетовые акценты по умолчанию |
| Светлая | светлая | холодный синий |
| Песочная | светлая | тёплая терракота |
| Графит | тёмная | стальной синий |
| Полночь | тёмная | глубокий фиолетовый |

## Модели

| Модель | Диск | Скорость | Точность | Заметки |
| --- | --- | --- | --- | --- |
| Large v3 Turbo · Компакт | 632 МБ | хорошо | лучшая | По умолчанию. Сжатые turbo-веса. |
| Large v3 Turbo | 1.6 ГБ | хорошо | лучшая | Та же модель без сжатия. |
| Small | 486 МБ | отлично | нормально | Старые Mac, чёткая речь. |
| Base | 148 МБ | отлично | слабо | Совсем маленькая. |

Все модели — CoreML-сборки
[Argmax WhisperKit](https://github.com/argmaxinc/argmax-oss-swift), работают на
Apple Neural Engine. Файлы лежат в
`~/Library/Application Support/Hush/Models`.

## Приватность

В Hush есть сеть только для одной загрузки модели с Hugging Face. Аудио
хранится в памяти, распознаётся на устройстве и выбрасывается после получения
текста. На диск ничего не пишется, если только ты сам не включил историю — она
остаётся в Application Support.

## Если что-то не работает

- **Хоткей не срабатывает** — включи Accessibility для Hush, после установки новой
  сборки выключи и включи тумблер заново. Если не помогло — включи ещё Input
  Monitoring и перезапусти приложение.
- **Fn открывает эмодзи** — отключи System Settings → Keyboard → Dictation (и
  шорткат «Press 🌐 key») либо выбери другой хоткей в Hush.
- **Текст не вставляется** — проверь Accessibility; иначе Hush скопирует текст в
  буфер.
- **Модель не скачивается** — проверь сеть и повтори в **Настройки → Модель**.

## Сборка из исходников

Нужны macOS 14+ и Xcode Command Line Tools. Полный Xcode не требуется.

```bash
xcode-select --install
git clone https://github.com/Vitali-lab/hush.git
cd hush
./scripts/build_app.sh
open dist/Hush.app
```

Структура проекта и флаги разработки — в [DEVELOPMENT.md](DEVELOPMENT.md),
сборка для Windows — в [windows/README.md](windows/README.md).
