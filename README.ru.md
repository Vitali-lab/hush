# Hush

**Говори тихо. Печатать будем мы.**

Локальная диктовка для macOS. Зажми клавишу, скажи что нужно, отпусти — текст
появится у курсора в любом приложении. Без аккаунта, облака и телеметрии.

[English version →](README.md)

```
Hush.app · ~8 МБ · macOS 14+ · Apple Silicon (Intel собирается из исходников)
```

## Что умеет

- **Диктовка где угодно** — Slack, почта, Cursor, терминал, браузер. Текст
  вставляется в поле с курсором, поэтому работает любое поле ввода.
- **Два языка, один переключатель** — русский или английский для интерфейса и
  распознавания одновременно. RU слушает только русский, EN — только
  английский. Никаких угадываний.
- **Любой хоткей** — удерживай Fn, правый Option, комбинацию клавиш или запиши
  свою клавишу в настройках.
- **Полностью офлайн** — Whisper `large-v3` Turbo в CoreML, работает на Neural
  Engine. Аудио живёт в памяти и никуда не отправляется.
- **Легко для ресурсов** — ~130–200 МБ памяти при распознавании, модель грузится
  меньше двух секунд и выгружается после восьми минут тишины.
- **Пять тем** — Системная, Светлая, Песочная, Графит, Полночь. Две светлые, две
  тёмные и одна следует за macOS.
- **Мелочи для удобства** — свои слова, сниппеты, удаление слов-паразитов,
  звуковой отклик, история с поиском, автозапуск.
- **Тихо по дизайну** — только меню-бар, без иконки в Dock и фоновых демонов.

## Чего здесь нет

Записи встреч, заметок, AI-агентов, командных пространств, аккаунтов, облачной
синхронизации и аналитики. Это хорошие продукты, но это не Hush.

## Установка

### macOS 14 (Sonoma) или новее

**Нужно:** macOS 14+, Xcode Command Line Tools (полный Xcode не требуется),
~1 ГБ свободного места под модель.

1. Один раз поставь инструменты разработчика:

   ```bash
   xcode-select --install
   ```

2. Склонируй и собери:

   ```bash
   git clone https://github.com/Vitali-lab/hush.git
   cd hush
   ./scripts/build_app.sh
   ```

3. Перенеси приложение и запусти:

   ```bash
   cp -R dist/Hush.app /Applications/
   open /Applications/Hush.app
   ```

   Можно запускать и прямо из `dist/Hush.app`.

4. При первом запуске разреши:

   - **Микрофон** — чтобы слышать тебя.
   - **Универсальный доступ (Accessibility)** — для глобального хоткея и вставки
     текста в другие приложения. macOS может попросить перезапустить Hush.
   - **Речевую модель** — одна загрузка (~630 МБ), дальше всё офлайн.

> Приложение подписано локальным сертификатом разработчика, без нотаризации.
> Если копируешь готовый `.app` на другой Mac, собери его там или сними карантин:
> `xattr -dr com.apple.quarantine /Applications/Hush.app`.

**Apple Silicon** — основная цель (Neural Engine). На Intel всё собирается из
того же исходника, но CoreML уходит на CPU/GPU и работает медленнее.

### Windows

**Пока недоступно.** Hush — нативное SwiftUI/AppKit-приложение на API, которых
на Windows нет: Accessibility-вставка, CoreML на Neural Engine, меню-бар.
Версия для Windows технически возможна, но это отдельное приложение, а не
пересборка — подробнее в разделе [Windows и Linux](#windows-и-linux).

### Linux

**Пока недоступно.** По той же причине: системный слой пришлось бы переписывать
под X11/Wayland и PulseAudio.

### Удаление (macOS)

```bash
rm -rf /Applications/Hush.app
rm -rf ~/Library/Application\ Support/Hush
```

Затем убери Hush из System Settings → Privacy & Security → Accessibility и
Microphone.

## Как пользоваться

| Действие | По умолчанию |
| --- | --- |
| Старт / стоп диктовки | Зажми `Fn`, говори, отпусти |
| Отмена во время записи | `Esc` |
| Открыть настройки | `⌘ ,` |
| Выход | `⌘ Q` |

Хоткей настраивается полностью в **Настройки → Основное → Горячая клавиша**:

1. Нажми **Записать**.
2. Нажми любую комбинацию, либо одну клавишу Fn / F1–F20 / модификатор.
3. Выбери **Удерживать** или **Нажатие — старт/стоп** (без удержания).

Обычным буквам и цифрам нужен модификатор (⌘, ⌥, ⌃, ⇧), чтобы диктовка не
включалась во время набора. F-клавиши и Fn работают сами по себе. Пресеты: `Fn`,
`Правый ⌥`, `Fn ×2`, `⌃⌥Пробел`.

После отпускания текст вставляется у курсора. Если нет доступа Accessibility,
Hush копирует текст в буфер и сообщает об этом в пилюле.

### Если хоткей не работает

- Включи **Accessibility** для Hush: System Settings → Privacy & Security →
  Accessibility. После пересборки приложения выключи и включи тумблер заново.
- **Fn открывает эмодзи?** Отключи System Settings → Keyboard → Dictation (и
  шорткат «Press 🌐 key») либо выбери другой хоткей в Hush.
- **Текст не вставляется?** Проверь Accessibility; иначе Hush скопирует текст в
  буфер и покажет «Скопировано».

## Языки и темы

Переключатель языка в **Настройки → Основное** (или `EN / RU` в поповере
меню-бара) меняет и интерфейс, и язык распознавания.

- **English** — Whisper распознаёт только английский.
- **Русский** — Whisper распознаёт только русский. Весь интерфейс переведён.

Темы находятся в **Настройки → Основное → Тема**:

| Тема | Режим | Характер |
| --- | --- | --- |
| Системная | следует за macOS | фиолетовые акценты по умолчанию |
| Светлая | светлая | холодный синий |
| Песочная | светлая | тёплая терракота |
| Графит | тёмная | стальной синий |
| Полночь | тёмная | глубокий фиолетовый |

Темы перекрашивают плавающую пилюлю, кнопки, тумблеры и поповер меню-бара.

## Модели

| Модель | Диск | Скорость | Точность | Заметки |
| --- | --- | --- | --- | --- |
| Large v3 Turbo · Компакт | 632 МБ | хорошо | лучшая | По умолчанию. Сжатые turbo-веса. |
| Large v3 Turbo | 1.6 ГБ | хорошо | лучшая | Та же модель без сжатия. |
| Small | 486 МБ | отлично | нормально | Старые Mac, чёткая речь. |
| Base | 148 МБ | отлично | слабо | Совсем маленькая, заметно слабее. |

Все модели — CoreML-сборки
[Argmax WhisperKit](https://github.com/argmaxinc/argmax-oss-swift), работают на
Apple Neural Engine. Файлы лежат в
`~/Library/Application Support/Hush/Models`.

### Почему эта модель

- **Русский**: large-v3 Turbo хорошо держит русскую пунктуацию и смесь
  русский/английский, а сжатая 626 МБ версия сохраняет почти всё качество.
- **Ресурсы**: в локальном тесте 8-секундный русский клип загрузил модель за
  1.8 с и распознался за 2.3 с суммарно при пике RSS 130 МБ.
- **Без Python и сервера**: CoreML работает внутри приложения. Нечего
  запускать, не за чем следить, вентиляторы не воют.

## Приватность

В Hush есть сеть только для одной загрузки модели с Hugging Face. Аудио
хранится в памяти, распознаётся на устройстве и выбрасывается после получения
текста. На диск ничего не пишется, если только ты сам не включил историю — она
остаётся в Application Support.

## Сборка и разработка

```bash
swift build                    # debug-бинарник
swift run Hush                 # запуск из терминала
./scripts/build_app.sh         # подписанный .app в dist/
./scripts/make_icon.sh         # пересобрать иконку
```

Служебные команды для скриншотов и проверок:

```bash
.build/debug/Hush --transcribe path/to/audio.wav   # вывести транскрипцию
.build/debug/Hush --selftest                       # проверки текста и настроек
.build/debug/Hush --render-ui /tmp/previews        # отрендерить SwiftUI-превью
.build/debug/Hush --capture-ui /tmp/shots          # снять реальные окна
```

Структура проекта:

- `Audio/HotkeyManager` — глобальный хоткей через `NSEvent`-мониторы.
- `Audio/AudioRecorder.swift` — запись с микрофона и ресемплинг в 16 кГц.
- `Speech/TranscriptionService.swift` — ленивая загрузка модели и декодирование.
- `Text/TextProcessor.swift` — слова-паразиты, словарь, сниппеты, пробелы.
- `System/TextInserter.swift` — вставка через буфер с восстановлением.
- `UI/HUD` — неактивирующая плавающая пилюля с живой волной.
- `UI/Settings` — пять небольших вкладок без визардов.

## Windows и Linux

Идея портируется, а системная обвязка — нет:

- **UI** — SwiftUI заменится на Tauri/Electron или нативный WinUI.
- **Аудио** — WASAPI (Windows) / PulseAudio или PipeWire (Linux) вместо
  AVFoundation.
- **Инференс** — CoreML/ANE там нет. Нужен `whisper.cpp` с Vulkan/CUDA/DirectML
  или CPU, либо `whisper-onnx`. Модель на 632 МБ всё ещё работает на современном
  CPU, но ждать придётся в 2–5 раз дольше реального времени, а не в 10–30 раз
  быстрее.
- **Вставка** — `SendInput` + UIAutomation на Windows, xdotool/ydotool или
  input-method на Linux.
- **Упаковка** — MSIX/NSIS на Windows, AppImage/deb/rpm на Linux.

То есть версия для Windows реалистична, но это второе приложение, которое
разделяет текстовый пайплайн и выбор модели, а не галочка в сборке. Если это
станет целью — разумный путь — кроссплатформенное ядро на Rust/Tauri.
